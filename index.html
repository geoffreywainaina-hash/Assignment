VERSION CONTROL SYSTEMS

A VCS is software that records changes made to files over time.

It allows users to :

  1. Track Changes.
  2. Restore previous versions.
  3. Work on different versions of a project.
  4. Collaborate with other developers.
  5. Identify who changed what and when.
  6. Experiment without destroying the main project.

GIT vs GITHUB

These two are often confused. Git is not GitHub.

Git is a version Control System while GitHub is a platforming for hosting Git repositories and collaborating.

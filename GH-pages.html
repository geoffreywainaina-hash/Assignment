GH-PAGES

GitHub Pages is a service from GitHub that lets you put a website online fo free.

What can GitHub Pages host?

GitHub Page is mainly for static websites.

This means:

  1. HTML
  2. CSS
  3. JavaScript
  4. Images
  5. Fonts/assests

But not server-side application such as:

  1. Pyton backend X
  2. Node.js/Express server X
  3. PHP X
  4. MYSQL databse X
